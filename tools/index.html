Which tool fits?

6 questions. Ranked answers with reasons, study threads, and deep links.

Question 1 of 6

Where does your code live?

Source hosting decides half the answer — co-located CI wins on integration.

Question 2 of 6

Who runs infrastructure?

No ops team means SaaS; a platform team unlocks self-hosted power.

Question 3 of 6

How much Kubernetes?

K8s estates pull toward GitOps; the rest stays push.

Question 4 of 6

Audit and compliance pressure?

Strict audit loves self-hosted evidence trails.

Question 5 of 6

Team size?

Solo ships fastest on SaaS; fleets need control.

Question 6 of 6

Where do releases land?

The runtime picks the delivery model — K8s means pull.

TOOL CATALOG12 TOOLS

Jenkins

Popularity★★★★☆4/5
What
Self-hosted automation server: controllers schedule, agents execute pipelines as code.
When
Regulated or air-gapped estates, complex heterogeneous builds, zero per-minute cost.
Why
Total control over execution, deepest plugin ecosystem, proven at scale.
How
Jenkinsfile on controller, stages on labeled agents, credentials via bindings.

Read in book →

GitHub Actions

Popularity★★★★★5/5
What
CI/CD built into GitHub: workflows of jobs and steps on hosted or self-hosted runners.
When
Source already on GitHub, small teams wanting zero-infra CI.
Why
Fastest path from push to green; PR checks and Marketplace built in.
How
YAML in .github/workflows, jobs with needs DAG, environments as gates.

Read in book →

GitLab CI

Popularity★★★☆☆3/5
What
Pipeline engine inside GitLab: single YAML driving stages, runners, review apps.
When
Single-platform shops wanting repo plus pipeline plus envs in one product.
Why
Review apps per MR and merge trains come free with the platform.
How
.gitlab-ci.yml stages with needs DAG, rules gating, runners by tags.

Read in book →

ArgoCD

Popularity★★★★☆4/5
What
GitOps operator for Kubernetes: in-cluster agent pulls desired state from git.
When
Kubernetes fleets needing pull-model audit and env-per-branch scale.
Why
Cluster creds never leave the cluster; git revert is the rollback.
How
Application manifests + sync waves; ApplicationSets fan out envs; manual sync gates prod.

Read in book →

Docker

Popularity★★★★★5/5
What
Container runtime and image format: freeze the app plus its OS userland.
When
Every pipeline that must kill works-on-my-machine drift.
Why
Identical bits from laptop to CI to prod; BuildKit caches keep it fast.
How
Multi-stage Dockerfiles, BuildKit secrets, push digests to a registry.

Kubernetes

Popularity★★★★★5/5
What
Container orchestrator: desired-state scheduler for pods, services, jobs.
When
Fleets sharing clusters, elastic runners, pull delivery targets.
Why
Bin-packing plus self-heal plus one API for runners and releases.
How
Manifests or Helm charts applied by hand, CI push, or ArgoCD pull.

Helm

Popularity★★★★☆4/5
What
Package manager for Kubernetes: templated charts with per-env values.
When
K8s releases needing versioned, repeatable installs across envs.
Why
One chart, many envs — diffs are value diffs, not manifest forks.
How
Chart plus values per env, helm upgrade with pinned image digests.

Terraform

Popularity★★★★★5/5
What
Infrastructure as code: declare envs, plan the diff, apply gated.
When
Environments that must be reviewable, repeatable, and drift-checked.
Why
Plan output is the review; state per env bounds the blast radius.
How
Modules pinned by version, remote state with locking, plan on PR.

Prometheus

Popularity★★★★☆4/5
What
Metrics engine: scrapes numeric time series, alerts on burn rate.
When
Any service needing SLO alerts and capacity signals.
Why
One query language over every target; alert on budgets, not blips.
How
Scrape targets, PromQL rules, Alertmanager with runbook links.

Grafana

Popularity★★★★★5/5
What
Unified dashboards over Loki, Prometheus, and traces.
When
Teams drowning in separate UIs for logs versus metrics.
Why
One glass pane with version annotations on every deploy.
How
Data sources plus dashboards as code, alerts beside the graphs.

Loki

Popularity★★★☆☆3/5
What
Log aggregation indexed by labels, queried with LogQL.
When
Exact-error forensics without paying full-text index prices.
Why
Labels keep it cheap; pairs with Prometheus metrics and Grafana.
How
Promtail DaemonSet ships lines, LogQL filters by labels and content.

Read in book →

GHCR / Registries

Popularity★★★☆☆3/5
What
Artifact storage and distribution: images, SBOMs, attestations.
When
Every pipeline that promotes the same digest end to end.
Why
Immutable digests make rollback a redeploy, not a rebuild.
How
Push by SHA tag, sign with Cosign, attest provenance, expire aggressively.
