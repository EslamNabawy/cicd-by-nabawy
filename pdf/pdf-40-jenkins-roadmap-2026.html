THE ROADMAP

Jenkins ships on cadence, not calendar — every week a new release, every four weeks a stabilized LTS, security fixes whenever they are needed. The 2026 roadmap is organized into horizons, not hard dates, because contributor bandwidth decides when an initiative ships.

01 / Release Cadence — Current Model

Unlike vendor-driven products, Jenkins never announces a "Jenkins 3.0." It evolves as a rolling train of weekly releases; the LTS line is a curated snapshot for conservative upgraders.

TrackRhythmWho should follow
WeeklyEvery week (2.545 → 2.566+ in 2026)Teams that want features fastest; accept more churn
LTSCut every ~4 weeks + backportsMost production controllers — stable, patched
SecurityAs needed via jenkinsci-advisoriesEveryone — apply out-of-band when CVE drops
2026 SHIPPED — 2.545 (Jan) Java 21+ required on controller · 2.552 (Feb) experimental Plugin Manager UI + revamped Clouds page · 2.554 (Mar) script console adapted for new UI · 2.556 (Mar) Spring Security 7 + Spring Framework 7 · LTS 2.541.1 (Jan) unified RPM repo, new GPG key for RPM/DEB.

02 / How Horizons Work

RELEASED
PREVIEW
CURRENT
NEAR TERM
FUTURE

Released is done. Preview is usable but still changing. Current is under active development. Near Term is next up once bandwidth allows. Future has consensus but no active work. Treat Near/Future as directional priorities — the Jenkins project explicitly warns they are not committed dates.

READING RULE

Jenkins does not commit to delivery dates — all initiatives depend on volunteer/contributor availability. Track progress via the live roadmap.yml on GitHub, not via this snapshot.

04 / End-User Experience & Interface

  • Plugin Manager UI revamp — Preview → shipping incrementally. Experimental UI landed in 2.552; full rollout is staged across weeklies. Expect iterative polish, not a flag day.
  • Look & Feel updates — Current. Systematic styling modernization across the web UI.
  • Accessibility — Near Term. A11y pass after the style layer stabilizes.
  • Full interface rework — Future. Larger overhaul; community consensus exists, no active implementation yet.
  • Already released: Dark Theme, Configuration UI (tables → divs), Theme Manager plugin.

WHAT THIS MEANS IN PRACTICE

If you maintain internal Jenkins docs/screenshots, budget for UI drift through 2026. The Plugin Manager and Clouds pages have already changed shape — automation (Puppet/JCasC) that screen-scrapes the UI will need updates.

Misreadings · Checklist · Next

12 / Failure Modes — Roadmap Edition

TREATING NEAR TERM AS A COMMITMENT

The most common misread. Near/Future are priorities ordered by contributor interest, not sprint commitments. A "Near Term" label is not a quarter promise — it means "next up when someone can staff it." Plan adoption as if/when, not when.

  • Pinning automation to weekly UI screenshots — UI/UX is actively churning (Plugin Manager, Look & Feel). Gate UI automation behind CSS selectors and cache-busting, or prefer JCasC/Groovy init over scraping.
  • Ignoring the cert window — MSI DigiCert expiry May 2026 is the infra team's top priority; Windows install flows that verify publisher certs can break if you lag the migration.
  • Staying on Puppet assumptions — Puppet → Ansible is in progress. If you contribute infra or mirror infra patterns internally, expect playbook drift.
  • Assuming "Pipeline as YAML" replaces Groovy tomorrow — it's Preview. Groovy Jenkinsfile and JTE remain the production path; YAML is additive.

13 / Operator Checklist

ADOPT — LTS line + advisories; track roadmap.yml weekly if you depend on Preview items. PLAN — Java 21 now mandatory; qualify JDK 25 early; Windows Server 2025 qualification path. HARDEN — Script Security granular approvals available now — move off blanket approvals. PREP — CloudEvents and pluggable log/storage for Tekton-interop experiments.
Q: Should we wait for the "full UI rework" before upgrading Jenkins?
A: No. That rework has consensus but no active development. Upgrade on the LTS cadence; the incremental UI improvements (dark theme, Plugin Manager) ship steadily regardless.
